# OPF App Prototype

Prototipo navegable de **OPF — Own Pet Food**, centrado exclusivamente en la Fase 1 (perros y gatos).

## Stack
- React
- Vite
- React Router
- Lucide icons
- CSS responsive con apariencia iOS

## Ejecutar
```bash
npm install
npm run dev
```

## Alcance actual
Incluye Home, Salud, Nutrición, escáner simulado, Perfil, Peso, Línea de vida, Expediente veterinario, Comunidad, navegación inferior y placeholders para los siguientes módulos de Fase 1.

Los datos son mock data: este repositorio representa una maqueta visual e interactiva, no el producto final ni ofrece diagnóstico veterinario.
